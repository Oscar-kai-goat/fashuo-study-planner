# 法硕备考助手（静态版）

这是「法硕备考助手」的 GitHub Pages 静态版本，无需后端服务器即可运行。

## 数据存储说明

静态版使用浏览器本地存储（localStorage）保存学习计划与打卡数据。数据仅保存在当前浏览器中，不会在不同设备或不同访客之间同步。首次打开时，会从 state.json 载入一份初始数据（含此前的备考计划与进度）。

如需迁移数据或跨设备使用，请使用页面内的「导出 JSON 备份」与「导入 JSON」功能。

## 文件说明

- index.html：单页应用，已关闭服务端模式，仅用浏览器本地存储。
- state.json：首次访问的初始数据种子。
- .nojekyll：告知 GitHub Pages 不做 Jekyll 处理。
